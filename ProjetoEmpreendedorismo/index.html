Histórico e acompanhamento

Banco de dados local

Estrutura equivalente em SQL, para a documentação do trabalho:

CREATE TABLE ocorrencias (
  id        INTEGER PRIMARY KEY AUTOINCREMENT,
  tipo      TEXT NOT NULL,
  local     TEXT NOT NULL,
  data      DATE NOT NULL,
  descricao TEXT NOT NULL,
  gravidade TEXT NOT NULL,   -- Baixa, Média, Alta, Crítica
  status    TEXT NOT NULL,   -- Aberta, Em andamento, Concluída
  chave     TEXT UNIQUE      -- impede registros duplicados
);
CREATE TABLE historico (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  ocorrenciaId  INTEGER REFERENCES ocorrencias(id),
  data          DATE,
  texto         TEXT
);
CREATE TABLE medidas (tipo TEXT PRIMARY KEY, texto TEXT);

Testes do sistema

Roda verificações de campos vazios, duplicidade, indicadores e persistência em um banco temporário. Os dados reais não são alterados.

    Conferir manualmente na apresentação

    • Diminuir a janela do navegador (ou abrir no celular) e verificar menu, cartões e tabelas.
    • Registrar uma ocorrência, recarregar a página (F5) e confirmar que ela continua na tabela.
    • Tentar salvar o formulário vazio e depois repetir o mesmo registro.
    • Abrir a aba Banco de dados e mostrar tabelas, índices e quantidade de registros.
    SecurityPro – protótipo acadêmico de empreendedorismo. Banco de dados local (IndexedDB), salvo neste navegador.
